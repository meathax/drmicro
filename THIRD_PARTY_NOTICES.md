New Dr. Micro board RTL, verification scripts, tests and documentation are offered under GPL-3.0-or-later; see LICENSE. This statement does not replace any third-party file license. The combined selected implementation is intended to be distributed under GPLv3-or-later, using the later-version option in GPLv2-or-later donors. Vendor-specific generated IP retains its own notices and requires separate review for a future hardware distribution.

* MAME's Dr. Micro driver: copyright Uki, BSD-3-Clause. Sound reference SN76496: copyright Nicola Salmoria; MSM5205: copyright Aaron Giles; both BSD-3-Clause. Full text at `reference/mame/docs/legal/BSD-3-Clause`; original source notices are retained. MAME is a behavioural checker, not DUT logic. COPYING describes MAME as a whole and is not a blanket relicensing of its selected BSD files.
* Template_MiSTer platform and emu example: GPL-2.0-or-later file headers, including Sorgelig copyright notices. Full GPLv2 at `reference/template/LICENSE`. Original tree is retained. The working sys tree has the small standard-language fixes recorded under patches. Generated Intel/Altera IP includes its original file-specific terms. Those files are retained for future compilation and excluded from game simulation.
* Bank Panic TV80 donor: Guy Hutchison, copyright 2004, MIT-style permission notice in every CPU file; based on Daniel Wallner's T80. All six matching HDL files and TV80.qip retained. Only tv80s plus its dependency closure is compiled. Derived tv80_core/tv80_mcode correct Mode 0 RET/NMI timing and LD A,R flags; original files remain intact, with exact patches retained. Bank Panic game logic, memory map, renderer and vendor dpram are not used in the DUT.
* JT89: Jose Tejada Gomez, GPL-3.0-or-later; original hdl and mixer dependencies retained with LICENSE and notices. `rtl/sn76496_jt89.sv` is the separately named maintained SN76496 adaptation. It attributes the donor register structure and replaces variant-dependent behaviour from the pinned MAME specification. Upstream JT89 is not represented as a verified SN76496 drop-in.
* JT5205: Jose Tejada Gomez, GPL-3.0-or-later. Original hdl/qip and GPL notices retained. A derived decoder file makes reset comparisons signed; its exact patch is recorded. Timing and decoder execute as synthesizable HDL, with interpolation disabled.

`third_party.lock.json` records full commit IDs, immutable content hashes, local destinations, selected modules, configuration, per-file header notices and patch hashes. `reports/tool_provenance.json` records optional locally downloaded simulator/compiler/reference binary provenance; those binaries are ignored and are not part of the source distribution.

Game ROMs are user-supplied proprietary assets. No game ROM or ROM-derived payload, RAM dump, graphics sheet, screenshot or WAV is included in source control. Reports may record hashes and observed metrics. MiSTer, MAME and Dr. Micro names identify their respective projects/game and do not imply endorsement or hardware certification.
