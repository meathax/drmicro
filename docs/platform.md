# Platform verification boundary

`sys/` is the complete single pinned Template_MiSTer tree with recorded language-correctness and explicit-input patches in `patches/`. The original is retained in `reference/template/sys`. Template's required `rtl/pll` files are present for future QIP recursion; the board runs on CLK_50M. The wrapper uses the exact `sys/emu_ports.vh` interface, byte HPS downloads (WIDE=0), 16-bit index, 27-bit address and 8-bit data. HPS joystick, PS/2 keyboard, DIP and reset are wired.

`sim/platform.f` elaborates emu, the complete game, real hps_io/video_calc, arcade_video, video_mixer, gamma_corr, scandoubler, HQ2x, video_freezer and screen_rotate. `sys_top.v` supplies its actual sync_fix definition; sys_top itself is not the elaborated root. There are no game or platform stubs in this check. It does not simulate the mixed-language scaler, physical HPS bridge, PLLs, HDMI output or DDR controller.

MISTER_FB is enabled in the future QSF and wrapper check. Rotation owns the DDRAM/FB outputs; they are not also tied inactive. Native/direct-video disables presentation rotation; software-controlled game flip remains inside the board. The independent rotation test tracks unique source-coordinate colour labels through DDR write addresses, byte enables and stride using an always-ready sink. It tests CCW direction and native bypass, not the physical memory controller or DDR backpressure. The pinned screen_rotate does not consume DDRAM_BUSY; that inherited interface limitation remains unvalidated on device.

The strict project checker follows QSF/Tcl/QIP references for Q13/Q17 selection, checks module uniqueness in explicit source lists and validates includes. Upstream optional generated .cmp metadata and jtag.cdf are listed separately. Passing this is only a source-path audit. Quartus 17.0.2 is now installed and explicit map/fit/sta checks are authorized. See their stage reports for actual results; no RBF or on-device claim is made.

Warnings remain visible in logs. Intentional unused menu/device ports, upstream expression widths, vendor initialization style and mixed synchronous/asynchronous donor reset are reviewed separately from board defects. A Verilator aggregate inout HPS_BUS/EXT_BUS dependency warning is a vector-level modelling artefact: extension select and return bits are tied inactive and the driven/read bit ranges differ. It is not waived as a board combinational loop.

Actual protocol tests cover valid and rejected ROM transfers, DIP index 254 without game reset, both joysticks, PS/2 make/break and OSD reset with CPU restart. Video tests cover coordinate colours in native mode and sample/line counts in native, gamma, scandoubled and HQ2x modes. The platform warning policy uses exact warning signatures and source hashes; it never grants blanket permission for new donor warnings.

The full Quartus root is sys_top, including the VHDL scaler and Intel platform IP. The direct game clock requires the recorded clock-select input patch: clk_vid uses input 1, HDMI PLL remains input 2. No additional game PLL or frequency change was introduced. Full synthesis inferred 1,507,777 block-memory bits and 15,105 registers; final fit resources and timing belong to their stage reports.
