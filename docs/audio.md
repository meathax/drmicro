# Audio baseline

`sn76496_jt89.sv` keeps JT89's latch/data decoding structure but replaces the variant-dependent oscillator, defaults, noise and amplitude logic. Original JT89 sources remain intact under `rtl/vendor/jt89`; INTERPOL16=0 was inspected, but its Sega feedback and high-frequency suppression cannot implement this target. The maintained derived module uses MAME SN76496 constructor values: feedback mask 0x10000, taps 0x04/0x08, output not negated, divider 8 at MAME's input-clock/2 stream rate (net /16).

Tone zero means 1024; counters start at zero and outputs at zero. Volume registers power on at zero (maximum). Noise mode powers on zero with period zero, matching the MAME initialization. Writes to register 6, including data-only writes, reset the feedback state but do not immediately overwrite the noise output latch or reset its timer. Fixed noise periods are 32,64,128 divided ticks; mode 3 uses twice tone 2's effective period. The 17-bit emulation state includes output delay; it is not a claim that the physical chip contains a 17-stage LFSR. The physical 15-stage recirculation plus output phase is represented by MAME's taps and feedback mask.

The amplitude table is floor(8191 / 10^(2*n/20)), n=0..14, with level 15 muted. Four unipolar channel levels add to 0..32764. All accepted writes are single system-clock strobes; no READY stalls are invented. Synthetic tests include consecutive-cycle writes and every noise mode, reset, rewrite, attenuation and tone zero.

JT5205 uses the recorded signed-reset-comparison patch (original retained), INTERPOL=0, VCLK_CEN=1, sel=1 (divide 64). Its vclk_o precedes cen_lo by one 384 kHz period. The ROM sequencer requests at vclk_o, completing a synchronous read in two clocks before the decoder samples. An immediate start write also requests a nibble. Restart commands take priority over pending fetches. Sample address wraps at 15 bits. The byte 70 stops at either nibble position.

JT5205 produces the previous captured nibble's result at the next sample strobe and fades reset output to -2. MAME resets its signal to zero; the donor output is therefore not claimed bit-exact to MAME. The independent decoder vectors explicitly account for the one-sample pipeline and -2 baseline, including positive/negative saturation. Starts occurring within the two-clock ROM fetch interval of a decoder edge remain a bus-phase abstraction requiring dedicated reference/PCB validation.

Mixer: signed 20-bit intermediate, PSG gains 1/8 each, ADPCM native 12-bit gain 3. This corresponds to reference relative gains .5/.5/.5/.75 with a common 1/4 headroom gain and 16× ADPCM normalization. Saturate to signed 16-bit; identical mono channels and AUDIO_S=1. No optional filtering is enabled. 48 kHz captures use deterministic nearest-sample observation of native chip levels, not an analogue filter model.

The integrated four-state sound test also checks 5,143 decoded samples through the real clock enables, sequencer, synchronous synthetic ROM, JT5205 and mixer: all 64 command pages, restarts and stop markers. Real-ROM two-player execution sends one sample command 0x21 during the observed death sequence; all 676/34/3,584 PSG writes and this ADPCM command match the reference per chip over 3,600 frames. This establishes command-stream agreement, not sample-exact analogue output or cross-chip event timing.
